# Scatter

A simple but (to be, still working on it) powerfull tool for scatter plots.

## Installation / how to use
1) From source:
```bash
git clone https://github.com/ManoahKinnaert/Scatter.git
cd Scatter 
python -m pip install -e .
```

2) Or directly:
```bash
python -m pip install git+https://github.com/ManoahKinnaert/Scatter.git 
```

3) Run the app:
```bash
python -m Scatter
```
